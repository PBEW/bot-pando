# Pandora's Night Heaven · Discord Bot

บอทบริหารร้าน **Pandora's Night Heaven** — สร้างจากระบบเดียวกับ **OLP-Noir** (เปิดบิล → พนักงานรับงาน → ลูกค้าส่งสลิป → แอดมินยืนยัน → แจ้งเตือนเวลา → รีวิว → ลงบัญชี/ตัดรอบ, Ticket DM, ลงเวลาพนักงาน, เช็คชื่อรายวัน) แล้วปรับเมนูให้ตรงกับร้าน Pandora

เขียนด้วย **discord.py 2.x** + **SQLite** + **Google Sheets (ไม่บังคับ)**

---

## 1. ติดตั้ง

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

```bash
copy .env.example .env
```

- `.env` → ใส่ `DISCORD_TOKEN`
- `config.json` → ถ้ายังไม่มี บอทจะคัดลอกจาก `config.example.json` ให้อัตโนมัติตอนรันครั้งแรก

ที่ Discord Developer Portal หน้า **Bot** เปิด **Server Members Intent** และ **Message Content Intent**
เชิญบอทด้วยสิทธิ์ `Manage Roles`, `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History` และลาก Role บอทไว้เหนือ Role On Duty

## 2. รันบอท

ดับเบิลคลิก `start_bot.bat` หรือ

```bash
.venv\Scripts\python bot.py
```

จากนั้นในเซิร์ฟเวอร์ (แอดมิน):

| คำสั่ง | โพสต์ที่ไหน |
|---|---|
| `/panel reception` | ห้องแอดมิน/รีเซปชั่น — เปิดบิล, ต่อเวลา, งานที่ดำเนินอยู่ |
| `/panel_request` | ห้องลูกค้า — สอบถาม, เมนู & ราคา, พนักงานวันนี้, โดเนท, Top Donate |
| `/panel_staff` | ห้องพนักงาน — เข้า/ออกงาน, ชั่วโมง, รายได้, งานของฉัน |
| `/panel_admin` | ห้องแอดมิน — สรุปยอด, Top Donate, แก้เวลาเข้างาน, ตัดรอบ |

### Private Party Room (หลายพนักงาน)
- ตอนเปิดบิล เลือกพนักงานหลายคนในเมนูพนักงาน — **คนแรกในรายการเป็นพนักงานหลัก** (ได้ปุ่มรับงาน/ปฏิเสธ) คนอื่นได้ DM แจ้งบิลพร้อมส่วนแบ่งของตัวเอง
- ยอดบิลแบ่งเท่ากันทุกคน แล้วคิดเปอร์เซ็นต์ส่วนแบ่งของแต่ละคน (`revenue_share`)
- แจ้งเตือนก่อนเริ่ม/ก่อนจบ, แจ้งชำระเงิน, แจ้งยกเลิก ส่งถึงพนักงานทุกคนในบิล
- Google Sheets บันทึก **แถวละ 1 พนักงาน** (Job ID เดียวกัน) เพื่อให้สูตรสรุปรายพนักงานถูกต้อง
- ลูกค้ากด **👥 พนักงานวันนี้** ที่ Request Panel เพื่อดูว่าใครเข้างานและรับงานแบบไหน (ไม่เห็นรายชื่อคนที่พนักงานไม่รับ) แล้วกด 💬 สอบถามเจ้าหน้าที่ เพื่อจองได้

### 💜 โดเนทด้วยตัวเอง (ลูกค้าทำเองได้)
- ลูกค้ากด **💜 โดเนทให้พนักงาน** ที่ Request Panel → เลือกพนักงาน → เลือก **โดเนทเงิน** (ใส่ยอดเอง) หรือ **Drink Friend** (ใส่จำนวน shot) → ใส่ข้อความถึงพนักงานได้
- บอทส่ง QR ทาง DM → ลูกค้าส่งสลิป → แอดมินกด ✅ ยืนยันในห้องแอดมิน (ระบบสลิปเดียวกับบิลปกติ ไม่ต้องรอพนักงานกดรับงาน)
- **ร้านไม่หักค่าโดเนทเงิน** พนักงานได้ 100% (`donate.staff_percent`) ส่วน Drink Friend คิดส่วนแบ่งตาม `revenue_share` ปกติ
- ยืนยันแล้ว: พนักงานได้ DM พร้อมข้อความและส่วนแบ่ง, ประกาศขอบคุณในห้อง `channels.announce` (ปิดได้ `donate.announce: false`), นับเข้า Top Donate / Google Sheets / สรุปตัดรอบ / รายได้พนักงาน
- ไม่ส่งสลิปภายใน `donate.expire_minutes` (60 นาที) ระบบยกเลิกให้อัตโนมัติ · ลูกค้ามีโดเนทค้างได้ทีละ 1 รายการ
- ตั้งยอดขั้นต่ำ/สูงสุดได้ที่ `donate.min_amount` / `donate.max_amount`

### 🏆 Top Donate
- ยอดโดเนท = ยอดบิลที่ **ชำระแล้ว** ทั้งหมดของลูกค้าในเดือนนั้น (ตามเวลาไทย)
- ทุกวันที่ 1 บอทประกาศผู้ชนะของเดือนก่อนในห้อง `channels.announce` และห้องแอดมิน ถ้ายอดอันดับ 1 ถึง `top_donate.min_amount` (ค่าเริ่มต้น 1,000 บาท) พร้อมบอกพนักงานที่ลูกค้าคนนั้นโดเนทให้มากที่สุด และ DM แจ้งผู้ชนะ
- ดูอันดับได้ตลอด: ปุ่ม 🏆 ใน Request Panel / เมนูแอดมิน หรือ `/top_donate [month] [year]`
- รันบอทครั้งแรกจะเริ่มนับจากเดือนปัจจุบัน (ไม่ประกาศย้อนหลัง)

## 4. `config.json` คีย์สำคัญ

| คีย์ | ความหมาย |
|---|---|
| `guild_id` | ID เซิร์ฟเวอร์ |
| `channels.admin` / `review` / `announce` | ห้องแอดมิน, ห้องรีวิว, ห้องประกาศ Top Donate |
| `roles.admin` / `staff` / `on_duty` | Role แอดมิน, พนักงาน (ใส่หลาย Role เป็น list ได้), On Duty |
| `roles.adult_verified` | Role ยืนยันอายุ 18+ (0 = ไม่ตรวจ) |
| `payment` | ชื่อบัญชี พร้อมเพย์ ลิงก์รูป QR |
| `services` | เมนูบริการ — แก้ราคา/เวลาได้เลย เมนูในบอทเปลี่ยนตาม |
| `rooms` | ห้องบริการ |
| `revenue_share` | % ส่วนแบ่งพนักงาน (ตั้งรายคนได้ด้วย Discord ID) |
| `top_donate` | เปิด/ปิด, ยอดขั้นต่ำ, จำนวนอันดับที่แสดง |
| `features.vip` | ระบบ VIP จาก OLP-Noir (ร้าน Pandora ปิดไว้ — เปิดได้ถ้าต้องการ) |
| `cutoff` | วัน/เวลาตัดรอบรายสัปดาห์ (ค่าเริ่มต้น เสาร์ 08:00) |

ความหมายของฟิลด์ใน `services`:
`per_unit` คิดต่อหน่วย · `multi_staff` + `included_staff` + `extra_staff_price` + `max_staff` บริการหลายพนักงาน · `addon_for` บริการเสริม `{บริการหลัก: นาทีที่บวกเพิ่ม}` · `adult_only` ต้องมี Role 18+ · `extend_only` ใช้ในเมนูต่อเวลาเท่านั้น · `require_room` ต้องเลือกห้อง

แก้ `config.json` แล้วกด 🔄 **โหลด config ใหม่** ในเมนูแอดมิน (หรือ `/reload_config`) ไม่ต้องรีสตาร์ต
*(ถ้าเพิ่ม/ลบบริการ ให้โพสต์แผงใหม่ด้วย `/panel reception` เพื่อให้รายการในเมนูอัปเดต)*

## ระบบเข้างานพนักงาน

ร้านเปิดวันละ 3-4 ชม. จึงใช้แบบ **กดเข้างานอย่างเดียว**

- 🟢 **เข้างาน** — มีฟอร์มให้พนักงานเลือก
  1. งานที่รับวันนี้ (เลือกได้หลายข้อ): 🔥 ห้องบริการ VIP · 🚪 ห้องปกติ · ☕ เล่นชิวๆ
  2. ⛔ คนที่ไม่รับเข้าห้องด้วย (เลือกจากรายชื่อ ไม่บังคับ) + พิมพ์ชื่อ/หมายเหตุเพิ่มได้

  แล้วบอทให้ Role On Duty และแจ้งห้องแอดมินพร้อมสรุป · กดเข้างานซ้ำ = แก้ไขงานที่รับวันนี้
- ตอนแอดมินเปิดบิล เมนูพนักงานแสดง 🟢 เข้างานแล้ว/⚪ ยังไม่เข้า + งานที่รับ ขึ้นคำเตือนถ้าบริการไม่ตรงกับที่พนักงานรับ และ **เปิดบิลไม่ได้ ถ้าลูกค้าอยู่ในรายชื่อคนที่ไม่รับ** ของพนักงานคนนั้น
- รายชื่อคนที่ไม่รับ เห็นเฉพาะพนักงานคนนั้นกับแอดมิน · ผูกบริการกับประเภทงานด้วยฟิลด์ `category` ใน `services` (แก้ตัวเลือกได้ที่ `attendance.accept_options`)
- ↩️ **ยกเลิกเข้างาน** — กดผิด กดยกเลิกได้ ลบรายการของวันนี้และถอด Role On Duty
- **ไม่มีปุ่มออกงาน** — ทุกวันตอนตี 1 (`attendance.day_cutoff_hour`) บอทปิดการลงเวลาของทุกคน บันทึกเวลาออก = ตี 1, ถอด Role, ลงชีต `Attendance` และส่งสรุปเข้าห้องแอดมิน ไม่มี DM เตือน
- 👥 **มาทำงานวันนี้** (`/staff_today`) — รายชื่อคนที่กดเข้างานตั้งแต่ตี 1 ล่าสุด
- แอดมินแก้เวลาได้ที่เมนูแอดมิน ✏️ หรือ `/attendance_fix`


### บิลค้าง (ตั้งเวลาได้ที่ `bill_timeout`)
- พนักงานไม่กดรับงานเกิน 15 นาที → แจ้งห้องแอดมิน 1 ครั้ง
- ลูกค้าไม่ส่งสลิป 15 นาทีหลังพนักงานรับงาน → DM เตือน 1 ครั้ง · ครบ 45 นาที → **ยกเลิกบิลอัตโนมัติ** (คืนสิทธิ์/ถอนเวลาต่อให้เหมือนยกเลิกปกติ) — บิลที่จองล่วงหน้าจะไม่ถูกยกเลิกก่อนเวลาเริ่มงาน
- สลิปรอแอดมินตรวจเกิน 10 นาที → แจ้งห้องแอดมิน 1 ครั้ง


## 💳 บัญชีรับเงินพนักงาน

- พนักงานกด **💳 บัญชีรับเงิน** ใน `/panel_staff` → กรอกธนาคาร/พร้อมเพย์, เลขบัญชี, ชื่อบัญชี (แก้ได้ตลอด ฟอร์มจะเติมข้อมูลเดิมให้)
- บันทึกในฐานข้อมูลบอท + แท็บ **บัญชีพนักงาน** ใน Google Sheets (เลขบัญชีเป็นข้อความ เลข 0 นำหน้าไม่หาย)
- กล่องสรุปในแท็บรอบบิลมีคอลัมน์ **💳 บัญชีรับเงิน** ต่อท้ายยอด "ส่วนแบ่ง (ต้องโอน)" ของแต่ละคน (จับคู่ด้วยชื่อพนักงาน)
- สรุปตัดรอบ / `/summary` ในห้องแอดมิน แสดงยอดที่ต้องโอน (ทศนิยม 2 ตำแหน่ง) + บัญชีของแต่ละคน ใครยังไม่ใส่จะขึ้น ⚠️
- ข้อมูลบัญชีเห็นเฉพาะพนักงานคนนั้นกับแอดมิน

## 🪙 เหรียญ Pandora

**ได้เหรียญ**
| จาก | ได้ |
|---|---|
| บิลที่ชำระแล้ว | 1 เหรียญ / 10 บาท (คิดจากยอดที่จ่ายจริงหลังหักคูปอง) |
| มาครั้งแรก | +20 |
| รีวิวผ่านอนุมัติ | +5 |
| ชนะ Top Donate ประจำเดือน | +100 |
| โดเนท | 1 เหรียญ / 20 บาท |
| วันอีเวนต์ | ×2 (แอดมินสั่ง `/coins event 2` · ปิดด้วย `/coins event 1`) |

บิลถูกยกเลิก → ดึงเหรียญคืน · บิลที่ฟรีทั้งใบจากคูปองไม่ได้เหรียญ · ไม่มาใช้บริการ 180 วัน → เหรียญหมดอายุ

**รางวัล** (ลูกค้ากด 🎁 แลกรางวัล ใน `/panel_request`) — เน้นรางวัลที่ไม่กระทบรายได้ร้าน/พนักงาน
| รางวัล | เหรียญ | ส่งมอบ |
|---|---|---|
| 📣 ประกาศขอบคุณ | 20 | บอทประกาศทันที |
| 🏷️ ฉายาพิเศษ 30 วัน | 50 | ใส่ `role_id` → บอทให้/ถอดเอง (0 = แจ้งแอดมิน) |
| 🃏 การ์ดแกล้ง | 100 | ลูกค้าเลือกท่าแกล้ง/เป้าหมาย/พนักงาน → พนักงานกดรับ (ได้โบนัส 10 บาท ร้านออก) หรือปฏิเสธ (คืนเหรียญ) · ไม่ตอบใน 2 ชม. คืนเหรียญ |
| 💸 ส่วนลด 20 บาท (บิล 150+) | 100 | คูปองตอนเปิดบิล · หักจากส่วนร้านเท่านั้น และไม่เกินส่วนร้าน → พนักงานได้เต็ม ร้านไม่ติดลบ |
| 👑 สั่ง CEO ได้ 1 คำสั่ง | 500 | ประกาศ + แอดมินนัดวัน (ไม่เกิน 10 นาที · ห้ามเงิน/ส่วนตัว/18+ · CEO ขอเปลี่ยนคำสั่งได้) |
| 🖼️ ขึ้น Hall of Fame (ถาวร) | 800 | ประกาศ + แอดมินติดชื่อ/รูปในร้าน |
| 🏰 Host Night 1 คืน | 1,000 | ประกาศ + แอดมินนัดวัน · ใส่ `role_id` + `role_hours` → แอดมินกด ✅ ใช้แล้ว บอทให้ Role ชั่วคราว |
| 💎 Role Pandora Collector | สะสมตลอดชีพ 1,000 | อัตโนมัติ (ใส่ `coins.collector_role_id`) |

- การ์ดแกล้ง: พนักงานต้องติ๊ก **🃏 รับการ์ดแกล้ง** ตอนเข้างาน (ค่าเริ่มต้นไม่ติ๊ก) ถึงจะถูกเลือกไปแกล้ง/เป็นเป้าหมายได้ · แก้รายการท่าแกล้งได้ในเมนู 🪙
- รางวัลบริการฟรีแบบเดิม "เลิกแลก" แล้ว — คูปองที่แลกไปก่อนหน้ายังใช้ได้จนหมดอายุ
- รางวัลที่ต้องนัดวัน (CEO / Hall of Fame / Host Night) คูปองอยู่ได้ 90 วัน
- คูปองใช้ได้ 30 วัน · ตอนเปิดบิลกดปุ่ม **🎟️ คูปอง** วนเลือกคูปองของคนจ่าย ราคาลดอัตโนมัติ
- **พนักงานได้ส่วนแบ่งเต็มเสมอ** ส่วนลดคูปองร้านออกเอง (บันทึกเป็น `coin_cost` และในหมายเหตุของชีต) · บิลฟรีทั้งใบบันทึกชำระแล้วอัตโนมัติ
- ยกเลิกบิลที่ใช้คูปอง → คูปองกลับมาใช้ได้
- ลูกค้า: 🪙 เหรียญของฉัน (ยอด, รางวัลถัดไปขาดอีกกี่เหรียญ, คูปอง, ประวัติ) · 🏅 อันดับนักสะสม (นับตลอดชีพ แลกของแล้วอันดับไม่ลด) · `/my_coins`
- แอดมิน: ปุ่ม **🪙 เหรียญ Pandora** ใน `/panel_admin` — 🔌 เปิด/ปิดระบบเหรียญ · เลือกลูกค้าดูยอด/ประวัติ · ➕ ปรับเหรียญ (พร้อมเหตุผล) · ✅ กดว่าใช้คูปองแล้ว (เช่น คูปองจองพนักงานก่อน) · 🎉 อีเวนต์ ×2 · ⚙️ ตั้งอัตรา/โบนัส/วันหมดอายุ · 🎁 จัดการรางวัล (แก้ / เพิ่ม / เลิกแลก / แก้ท่าแกล้ง) · 🏅 อันดับ
- คำสั่งเทียบเท่า: `/coins give` · `/coins check` · `/coins event`
- Google Sheets แท็บ **เหรียญ Pandora** บันทึกทุกการได้/ใช้ (ได้ = เขียว, ใช้ = แดง)
